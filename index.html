Work

Selected systems & full-stack projects

  1. kettle

    GitHub ↗

    A cycle-accurate CHIP-8 interpreter and emulator written from scratch in Rust. A core library handles the CPU, memory, 60Hz timers, and display buffer, and a separate SDL2 frontend handles the 15x-scaled window, keyboard input, and square-wave audio.

    Rust · SDL2 · Systems

  2. Cubic

    Live / Source ↗
    ★ Winner — Best Design @ StormHacks 2026

    Two-player co-op puzzle game where one player walks on the outside of a cube and the other is trapped inside. Solve puzzles across all 6 faces together using proximity voice chat and an AI partner for solo play.

    TypeScript · Node.js · Phaser · WebRTC · Gemini

  3. Cellar

    GitHub ↗

    A CLI password manager that generates and stores a unique password per entry in a single encrypted file on disk. Everything is protected with Argon2id key derivation and AES-256-GCM authenticated encryption.

    Python · Argon2id · AES-256-GCM · CLI

  4. Connect Four

    GitHub ↗

    A two-player Connect Four game communicating over a raw TCP socket. A multithreaded server manages game state, move validation, and win detection while broadcasting JSON updates to tkinter GUI clients.

    Python · Raw TCP Sockets · Multithreading · tkinter

  5. Turtle Trips

    GitHub ↗

    An AI-powered travel planner built at StormHacks 2025. Users enter a destination and the app generates a custom itinerary using Google Gemini, with Google Maps handling places, directions, and geocoding.

    Python · Flask · Gemini API · Google Maps

  6. MarketMimic

    GitHub ↗

    A web-based stock trading simulator for first-time investors. Track up to 50 tickers on a custom watchlist, view interactive historical price charts, and place simulated trades with virtual currency.

    Java · Spring · Maven · Docker · JS
